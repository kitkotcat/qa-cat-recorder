# QA Buddy Recorder v0.3.1 — backlog

## Product decision

QA Buddy Recorder ориентирован на **русскоязычных QA**.

Интерфейс приложения — русский. Английский используется только там, где это стандартная профессиональная терминология: `Bug Report`, `Test Case`, `Checklist`, `Network`, `Console`, `HTTP`, `JSON`, `Markdown`, `request`, `response`, `severity`, `priority`.

Language switch в пользовательском UI не нужен.

## P0

- Test Case Builder
- Checklist Builder
- Builder switch: Bug Report / Test Case / Checklist
- Новая сессия
- Сбросить draft
- Пересобрать draft
- Environment metadata
- Mascot v2: крупнее, хвост, усы
- Drag & Drop mascot
- сохранение позиции mascot
- screenshot привязывается к последнему step
- green CI

## P1

- step reorder
- session tags
- filters по step type
- screenshot-step reassignment
- session history
- IndexedDB для screenshot blobs

## Definition of Done

- UI полностью ориентирован на русскоязычного QA
- builders не удаляют raw evidence
- reset draft не удаляет session
- rebuild создаёт draft заново из steps
- New session очищает session, но сохраняет settings
- Environment автоматически собирается
- mascot drag сохраняет position
- build проходит локально и в GitHub Actions
