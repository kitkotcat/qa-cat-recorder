# QA Buddy Recorder v0.3.1 — статус и backlog

## Product direction

QA Buddy Recorder ориентирован прежде всего на **русскоязычных QA**.

Интерфейс приложения — русский. Английские термины используются там, где это стандартная профессиональная терминология: `Bug Report`, `Test Case`, `Checklist`, `Network`, `Console`, `HTTP`, `JSON`, `Markdown`, `request`, `response`, `severity`, `priority`.

## Реализовано в v0.3.1

- ✅ Bug Report Builder
- ✅ Test Case Builder
- ✅ Checklist Builder
- ✅ switch между Bug Report / Test Case / Checklist
- ✅ Новая сессия
- ✅ Сброс только текущего draft без удаления raw evidence
- ✅ Пересборка draft из текущих steps/evidence
- ✅ automatic Environment metadata
- ✅ mascot v2: крупнее, хвост, усы
- ✅ Drag & Drop mascot
- ✅ сохранение позиции mascot
- ✅ screenshot привязывается к последнему recorded step
- ✅ request duration
- ✅ slow request detection и configurable threshold
- ✅ RU-first UX
- ✅ local-only session storage
- ✅ GitHub Actions build

## Definition of Done для следующего публичного этапа

- README соответствует фактической версии и возможностям;
- build проходит через `npm ci && npm run build`;
- CI использует lock-файл;
- privacy-sensitive данные не сохраняются;
- repo не содержит secrets, `.env`, ключи и локальные артефакты;
- smoke flow Recorder проходит вручную в Chrome;
- permissions проверены перед Chrome Web Store publication.
