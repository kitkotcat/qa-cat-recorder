QA Cat Recorder — Privacy Policy

Последнее обновление: 5 октября 2026

Главная · Support

Данные

Во время активной QA-сессии расширение может локально обрабатывать URL посещаемых страниц, navigation, clicks, form interactions, safe form values, Screenshots, Network metadata, Console errors и технические metadata браузера, viewport и locale.

Sensitive data

Passwords, authentication tokens, API keys, OTP, PIN/CVV/security-code fields и payment-card numbers автоматически маскируются до сохранения.

Storage и передача

Session data хранится локально через chrome.storage.local. QA Cat Recorder не использует backend для session data, cloud sync, analytics или внешние AI API.

Data sharing и Limited Use

QA Cat Recorder не продаёт пользовательские данные и не передаёт recorded session data рекламным сетям или data brokers. Обрабатываемые данные используются только для основной функции QA recording и подготовки QA-артефактов и не используются для рекламы, creditworthiness, lending или иных несвязанных целей. Использование соответствует Chrome Web Store User Data Policy и Limited Use requirements.
