QA Cat Recorder 🐱

Chrome extension для ручного тестирования: Steps, safe test data, Screenshots, Network/Console evidence и QA-черновики.

Privacy Policy · Support · GitHub

Что умеет

  • Записывает шаги тестового сценария и navigation.
  • Сохраняет safe form values и маскирует sensitive values.
  • Создаёт Screenshots по явному действию пользователя.
  • Собирает Network/Console evidence.
  • Формирует Bug Report, Test Case и Checklist.

Privacy-first

QA Cat Recorder работает локально. Данные QA-сессии хранятся в chrome.storage.local и не отправляются на внешний backend.
